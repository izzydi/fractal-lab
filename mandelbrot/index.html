1

Ένας κανόνας, άπειρη λεπτομέρεια

Πάρε έναν μιγαδικό αριθμό c, ξεκίνα από το 0 και εφάρμοσε ξανά και ξανά τον κανόνα z → z² + c. Η ακολουθία που προκύπτει είτε μένει κοντά στο 0 είτε ξεφεύγει στο άπειρο.

Το σύνολο Mandelbrot είναι όλα τα c για τα οποία η ακολουθία μένει φραγμένη. Ο κανόνας χωράει σε μία γραμμή, αλλά το σύνορο του συνόλου έχει άπειρη λεπτομέρεια: όσο κι αν μεγεθύνεις, βρίσκεις νέες σπείρες, «ιππόκαμπους» και μικρά αντίγραφα του ίδιου του συνόλου.

Το 1980 ο Benoît Mandelbrot, στο ερευνητικό κέντρο της IBM, ήταν από τους πρώτους που το είδαν στην οθόνη υπολογιστή. Το 1975 είχε επινοήσει και τη λέξη fractal, από το λατινικό fractus (σπασμένος).

Στόχοι του μαθήματος

  1. Σ1Να αναπαριστάς μιγαδικούς αριθμούς ως σημεία του επιπέδου και να υπολογίζεις το z² και το |z|.
  2. Σ2Να εξετάζεις αν η ακολουθία z → z² + c μένει φραγμένη για συγκεκριμένα c.
  3. Σ3Να αποδεικνύεις γιατί αρκεί να ελέγχουμε αν |z| > 2.
  4. Σ4Να γράφεις σε Python έναν αλγόριθμο «χρόνου διαφυγής» με τον τύπο complex.

Ένας κανόνας μιας γραμμής, και δεν τελειώνει ποτέ!

4

Πώς φτιάχνεται η εικόνα

A

Ένα σημείο c

Κάθε σημείο (x, y) του επιπέδου είναι ένας μιγαδικός αριθμός c = x + yi. Εδώ c = −0,5 + 0,5i.

B

Η ακολουθία του c

Για c = −0,12 + 0,75i η ακολουθία γυρίζει σε κύκλο τριών σημείων. Για c = 0,35 + 0,45i βγαίνει από τον δίσκο στο 12ο βήμα.

C

Χρωμάτισε κάθε pixel

Κάνε το ίδιο για κάθε pixel. Αν δεν ξεφύγει, το βάφουμε μαύρο, αλλιώς το χρώμα του δείχνει σε πόσα βήματα ξέφυγε.

5

Τα μαθηματικά πίσω από την εικόνα

Ένας μιγαδικός αριθμός γράφεται z = x + yi, όπου i² = −1. Ας δούμε τι κάνει ο κανόνας και γιατί ο κώδικας σταματά στο 2.

1Μιγαδικοί ως σημεία

Ο αριθμός x + yi αντιστοιχεί στο σημείο (x, y). Το μέτρο του είναι η απόστασή του από την αρχή, με το Πυθαγόρειο θεώρημα:

|x + yi| = √(x² + y²)    |3 + 4i| = √(9 + 16) = 5

Στον κώδικα: complex(x, y) φτιάχνει τον αριθμό και abs(z) δίνει το μέτρο του.

2Το τετράγωνο ενός μιγαδικού

Αναπτύσσουμε την ταυτότητα και χρησιμοποιούμε ότι i² = −1:

(x + yi)² = x² + 2xyi + y²i² = (x² − y²) + 2xy·i

Για παράδειγμα (1 + i)² = 0 + 2i = 2i. Ο εξερευνητής κάνει ακριβώς αυτόν τον υπολογισμό με πραγματικούς αριθμούς, γιατί είναι πιο γρήγορος.

3Ποια c ανήκουν στο σύνολο;

Υπολογίζουμε τους πρώτους όρους z₁, z₂, z₃, … για τρία c:

cακολουθίαανήκει;−10, −1, 0, −1, …ναιii, −1 + i, −i, −1 + i, …ναι11, 2, 5, 26, 677, …όχι

Για c = −1 και c = i η ακολουθία κάνει κύκλο και μένει φραγμένη. Για c = 1 μεγαλώνει χωρίς όριο.

4Γιατί αρκεί να ελέγχουμε το |z| > 2;

Έστω ότι σε κάποιο βήμα |z| > 2 και |z| ≥ |c|. Από την τριγωνική ανισότητα:

|z² + c| ≥ |z|² − |c| ≥ |z|² − |z| = |z| · (|z| − 1)

Αφού |z| − 1 > 1, το μέτρο μεγαλώνει σε κάθε βήμα κατά έναν παράγοντα που κι αυτός μεγαλώνει, άρα |zₙ| → ∞. Αν |c| > 2, ήδη το z₁ = c ικανοποιεί και τις δύο συνθήκες. Επομένως όλο το σύνολο βρίσκεται μέσα στον δίσκο |c| ≤ 2.

5Η καρδιοειδής και ο κύκλος

Αν η ακολουθία πλησιάζει ένα σταθερό σημείο z* = z*² + c με |2z*| < 1, τότε c = w/2 − w²/4 με |w| < 1: αυτή είναι η κύρια καρδιοειδής. Οι κύκλοι δύο τιμών δίνουν τον δίσκο |c + 1| < 1/4. Ο εξερευνητής τα ελέγχει πρώτα και γλιτώνει χιλιάδες επαναλήψεις.

6Ομαλά χρώματα

Λίγο πριν ξεφύγει, το |z| σχεδόν τετραγωνίζεται σε κάθε βήμα, άρα το log₂(ln |z|) αυξάνεται περίπου κατά 1. Αν το αφαιρέσουμε από το n, ο αριθμός βημάτων γίνεται «συνεχής»:

ν = n + 1 − log₂(ln |zₙ|)

Έτσι ο εξερευνητής βγάζει χρώματα χωρίς λωρίδες. Η Python χρησιμοποιεί τον ακέραιο n, γι' αυτό η εικόνα της έχει λωρίδες.

Συμπέρασμα: το c ανήκει στο σύνολο Mandelbrot αν η ακολουθία 0, c, c² + c, … δεν βγαίνει ποτέ από τον δίσκο |z| ≤ 2
Από τα μαθηματικά στην Python

Στην Python οι μιγαδικοί είναι έτοιμοι: complex(x, y) φτιάχνει το x + yi, η γραμμή z = z * z + c εφαρμόζει τον κανόνα και το abs(z) > 2 ελέγχει αν το z ξέφυγε.

Ήξερες ότι;

Μέσα στο σύνολο Mandelbrot κρύβεται ο αριθμός π. Το 1991 ο Dave Boll μέτρησε πόσα βήματα χρειάζεται το c = −0,75 + ε·i για να ξεφύγει, για όλο και μικρότερα ε. Για ε = 0,01 χρειάζονται 315 βήματα, για ε = 0,0001 χρειάζονται 31.417, και γενικά το γινόμενο βήματα × ε πλησιάζει το π = 3,14159…
